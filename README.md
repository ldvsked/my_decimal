# my_decimal

Реализация собственной библиотеки my_decimal.h для работы с десятичными числами в языке C. Проект выполнен в рамках учебной программы с упором на структурное программирование, битовые операции и обработку финансовой информации.

## О проекте

Основная цель проекта заключалась в том, чтобы реализовать тип данных "decimal", отсутствующий в стандарте языка C. Этот тип критически важен для финансовых расчетов, где недопустимы погрешности вычислений, свойственные типам с плавающей точкой (IEEE 754). В рамках проекта реализованы арифметические операции, операции сравнения, преобразования и математические функции для работы с десятичными числами.

### Реализованные функции:

* **Арифметические операторы**: Сложение (`my_add`), вычитание (`my_sub`), умножение (`my_mul`), деление (`my_div`) с обработкой переполнений и банковским округлением.
* **Операторы сравнения**: Полный набор операторов сравнения (`my_is_less`, `my_is_equal`, `my_is_greater` и др.) с возвратом TRUE/FALSE.
* **Преобразователи**: Конвертация между decimal и типами int/float (`my_from_int_to_decimal`, `my_from_float_to_decimal`, `my_from_decimal_to_int`, `my_from_decimal_to_float`).
* **Математические функции**: Округление до ближайшего целого (`my_round`), округление в сторону отрицательной бесконечности (`my_floor`), отбрасывание дробной части (`my_truncate`), изменение знака (`my_negate`).

## Особенности реализации

### Двоичное представление

Decimal число реализовано в виде четырехэлементного массива 32-разрядных целых чисел (`int bits[4]`):

* `bits[0]`, `bits[1]`, `bits[2]` содержат 96-разрядное целое число (младшие, средние и старшие 32 бита соответственно).
* `bits[3]` содержит коэффициент масштабирования (биты 16-23) и знак (бит 31).
* Поддерживаются числа от -79,228,162,514,264,337,593,543,950,335 до +79,228,162,514,264,337,593,543,950,335.
* Коэффициент масштабирования от 0 до 28 (степень 10 для деления целого числа).

### Качество и проверка

* **Makefile**: Автоматизированная сборка. Доступны цели для компиляции статической библиотеки, тестов и генерации отчета о покрытии.
* **Модульное тестирование**: Полное покрытие unit-тестами с использованием библиотеки Check. Тесты покрывают все функции, включая краевые случаи и обработку ошибок.
* **Покрытие кода**: Генерация отчета gcov в формате HTML для визуализации покрытия (цель `gcov_report`).
* **Обработка ошибок**: Реализована корректная обработка ошибок конвертации, переполнения, деления на ноль и других исключительных ситуаций.

### Архитектура

Код написан с соблюдением принципов **структурного программирования**:

* Логика разбита на функциональные модули (арифметика, сравнение, преобразование, вспомогательные функции).
* Минимизировано дублирование кода через использование вспомогательных утилит.
* Использованы структуры данных для управления состоянием и масштабированием чисел.
* Отсутствует использование типа `__int128`.

## Запуск

1. Склонируйте репозиторий.
2. Соберите проект через терминал:

```bash
make my_decimal.a
```

3. Запустите тесты:

```bash
make test
```

4. Сгенерируйте отчет о покрытии:

```bash
make gcov_report
```

5. Использование в своем проекте:

```c
#include "my_decimal.h"

my_decimal a, b, result;
my_from_int_to_decimal(10, &a);
my_from_int_to_decimal(3, &b);
my_add(a, b, &result);  // result = 13
```

---

**Примечание**: При арифметических операциях используется банковское округление для чисел, не вмещающихся в мантиссу. Конечные нули могут как сохраняться, так и удаляться (за исключением функции `my_truncate`).
